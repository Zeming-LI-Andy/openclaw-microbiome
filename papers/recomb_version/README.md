# RECOMB 2027 manuscript workspace

基于 `../main.tex` 的会议版写作骨架，当前处于段落大纲阶段。核心定位是根据研究目标开展微生物组分析，覆盖 16S、参考驱动 shotgun 与组装驱动分析；异步执行与用户指导是支撑能力。不得将系统写成自主发现问题并纠正的系统。

- `outline.md`：正文定位、33 个段落核心句、证据边界、版面及正文图表安排。
- `appendix-outline.md`：唯一的附录规划文件；一个 Appendix、三个主题小节、9 个解释性段落，以及所需材料与正文的对应关系。
- `main.tex`：与两份大纲同步的英文 LaTeX 骨架；10 pt、Letter、1 inch 页边距，标题页包含摘要。已配置正文及单一 Appendix。

在同一 `main.tex` 中逐段扩写 `\topic{ID}{...}`。原有素材位于 `../figures/`，引用来源位于 `../refs.bib`；当前骨架不依赖外部图或文献文件，可在内置 LaTeX 编辑器中编译。正式稿需移除段落 ID 和规划提示，补入核验后的引用、图表与材料，并检查正文实际页数。

现有数值沿用原稿，尚未在本轮重跑实验或独立核验全部日志。实验与结果均按案例、稳健性、运行协调消融、运行中反馈排序；附录补充细节，主要证据与限制保留正文。
