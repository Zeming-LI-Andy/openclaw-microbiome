Fig. X (`papers\figures\microbioagent-architecture-image2-v7`) | MicroBioAgent system architecture. User requests and local workspace prompts enter an OpenClaw harness that binds the conversation to an analysis job, discovers and reviews relevant skills, constructs an analysis plan, dispatches individual steps and executes them. The agent dynamically selects study-appropriate procedures from a microbiome tool repository and resolves their required resources from a user-configured reference database repository. Upstream and downstream computation for 16S amplicon, reference-based metagenomic and assembly-based metagenomic analysis runs on user-controlled local infrastructure, where raw reads remain local. Figures, tables, reports and biological interpretations are delivered as user-facing results, while intermediate files, generated code, parameters, logs and software/database versions form the reproducibility record. During long-running computation, user messages and command-completion events provide separate routes for resuming the same agent session.

Fig. X (`microbioagent-workflow.pdf`) | Unified agent workflow for end-to-end reproduction of metagenomic studies. A study request is bound to a job before the analysis plan is confirmed. The agent selects step procedures from 16S amplicon, read-based shotgun and assembly/MAG routes, executes one step at a time, and verifies outputs before proceeding. For long steps, the agent yields while the command runs; user feedback can revise pending work, whereas command completion triggers output verification and continuation. Final artifacts and execution records are retained in the job directory.
