# AGENTS.md — openclaw-microbiome (repo guide for coding agents)

This file is for **developers / coding agents** working in this repository.
It is **not** the OpenClaw runtime bootstrap (that lives in `workspace/AGENTS.md`
and is merged into the OpenClaw agent workspace).

## What this is

OpenClaw plugin (`id: microbiome`) for 16S / shotgun metagenomics sessions:

- Plugin tool `mgx_create_job` — one conversation ↔ one analysis `job_id`
- Steps = Skills under `skills/` (OpenClaw `exec` + host conda), not a pipeline engine
- Runtimes / reference DB paths via registries; deploy paths are user-owned

Human install & config: READ `README.md`. 
Migrate a bio tool into a skill: READ `SKILL_CREATE.md`.

## Layout

| Path | Role |
|------|------|
| `src/` | Plugin TS: job tool, refs sync/resolve, catalog |
| `dist/` | Build output — do not edit by hand |
| `skills/` | Shipped OpenClaw skills (`openclaw.plugin.json` → `./skills`) |
| `workspace/` | Runtime prompts + registries for the OpenClaw agent workspace |
| `workspace/registry/` | `runtimes.yaml`; `references.yaml` (usually generated by sync) |
| `examples/` | Template `microbiome-refs.yaml` for `~/.openclaw/` |
| `catalog/` | Tool catalog YAML (copied into `dist` on build) |
| `scripts/` | Maint: sync-refs, dry-run, sync-manifest, copy-catalog |
| `patches/` | Version-pinned OpenClaw patch packs (do not edit upstream in-place) |
| `jobs/` | Local/dry-run job dirs (not necessarily production `jobsRoot`) |

## OpenClaw patches

Long-running analysis depends on background `exec` + `notifyOnExit` wake.
Required upstream fixes live under
`patches/openclaw-exec-session-wake/` (see that pack’s `README.md` +
`manifest.json` for the **exact OpenClaw version/commit** pin).

```bash
./patches/openclaw-exec-session-wake/scripts/apply-openclaw-patches.sh --check
./patches/openclaw-exec-session-wake/scripts/apply-openclaw-patches.sh
# rebuild + restart gateway after apply
```

Prefer updating / rebasing the patch pack over leaving dirty edits in
`../openclaw`.
